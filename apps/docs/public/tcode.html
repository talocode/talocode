$TCODE

The official Talocode utility token on Solana. Hold it, link a wallet, and claim monthly Cloud API credits. Credits are product usage, not cash.

What is live today

Hold-to-earn is live. You prove wallet ownership with a signature. The server reads the on-chain balance. Credits land in the same prepaid Cloud wallet that API keys spend.

  1. Hold $TCODE in a Solana wallet you control.
  2. Sign in to the Cloud Dashboard and open Wallet, or use Tera Blockchain Lab.
  3. Sign a one-time challenge to link that wallet to your project or Tera account.
  4. Claim at most once per UTC month. One wallet maps to one project.

What is not live

These are planned product mechanics. They are not available to claim today.

  • Contributor airdrops for merged pull requests
  • A redemption floor that converts $TCODE into credits at a fixed rate
  • Staking that gates extra product features

How to trade

$TCODE currently trades on Solana through the live mint above. Liquidity is still on a launch curve, so size orders carefully.
