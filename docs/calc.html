CalcLane

Scientific calculator. This page does not spend a credit. The same expression on the API costs 1 credit, which is $0.01.

1

The same call for an agent

Scientific mode is the default. Send angle as deg, rad, or grad.

curl https://api.talocode.site/v1/calclane/evaluate \
  -H "Authorization: Bearer $TALOCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"expression":"sin(90)","angle":"deg"}'

Also: cos, tan, asin, acos, atan, log, ln, sqrt, cbrt, abs, exp, fact, pi, e, ^, and mod. % is remainder, not percent.
